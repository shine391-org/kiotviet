## 🎯 MỤC TIÊU

Bổ sung fields thiếu vào table `customers` để hỗ trợ:

- **Xuất hóa đơn VAT/E-Invoice** (bắt buộc từ 2026)
- Quản lý khách hàng doanh nghiệp
- Thông tin ngân hàng và giấy tờ tùy thân

**Tech Stack:** Prisma ORM + PostgreSQL + Next.js API Routes

---

## 📋 YÊU CẦU

### Fields cần bổ sung:

**1. Thông tin cơ bản (6 fields):**

- `phone2` (String?) - Điện thoại phụ
- `gender` (Enum?) - MALE/FEMALE/OTHER
- `facebook` (String?) - Facebook URL
- `customer_type` (Enum) - INDIVIDUAL/COMPANY/HOUSEHOLD (default: INDIVIDUAL)
- `company_name` (String?) - Tên công ty
- `notes` (Text?) - Ghi chú

**2. Thông tin xuất hóa đơn (9 fields):** ⚠️ **QUAN TRỌNG cho E-Invoice**

- `tax_code` (String?) - Mã số thuế (10-14 ký tự số)
- `buyer_name` (String?) - Tên người mua
- `invoice_company_name` (String?) - Tên công ty trên hóa đơn
- `invoice_address` (String?)
- `invoice_province`, `invoice_district`, `invoice_ward` (String?)
- `invoice_email`, `invoice_phone` (String?)
- `cccd_cmnd` (String?) - Số CCCD/CMND
- `id_number` (String?) - Passport/Lý chiếu

**3. Thông tin ngân hàng (2 fields):**

- `bank_account` (String?) - Số tài khoản
- `bank_name` (String?) - Tên ngân hàng

### Constraints:

- Tất cả fields optional (nullable)
- `tax_code` unique per organization: `@@unique([organizationId, taxCode])`
- Index trên `tax_code` để query nhanh

## 🛠️ IMPLEMENTATION GUIDE

### Bước 1: Update Prisma Schema

**File:** `apps/api/prisma/schema.prisma`

**Logic:**

1. Mở model `Customer`
2. Thêm 17 fields mới (6 + 9 + 2)
3. Định nghĩa enums: `CustomerType`, `Gender` (nếu chưa có)
4. Thêm index: `@@index([taxCode])`
5. Thêm unique constraint: `@@unique([organizationId, taxCode], name: "unique_tax_code_per_org")`

**Notes:**

- Dùng type `String?` cho hầu hết
- `notes` dùng `String? @db.Text`
- Enums default values nếu cần

### Bước 5: Update API (Simple)

**Các endpoints cần update:**

**POST `/api/customers`:**

- Accept fields mới trong request body
- Validate: `tax_code` format (10-14 digits nếu có)
- Validate: `customer_type` enum
- Pass vào `prisma.customer.create()`

**PUT `/api/customers/:id`:**

- Accept fields mới
- Same validation rules
- Pass vào `prisma.customer.update()`

**GET `/api/customers` + GET `/api/customers/:id`:**

- Fields mới tự động return (Prisma auto-include)
- Không cần thay đổi code

**Validation logic:**

```tsx
if ([data.tax](http://data.tax)_code) {
  // Validate: 10-14 ký tự số
  if (!/^\d{10,14}$/.test([data.tax](http://data.tax)_code)) {
    throw error;
  }
}

if (data.customer_type) {
  // Validate enum
  if (!['INDIVIDUAL', 'COMPANY', 'HOUSEHOLD'].includes(data.customer_type)) {
    throw error;
  }
}
```

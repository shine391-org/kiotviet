## 🔄 API Integration

### Data Flow
1. **Load Price Lists:** Calls `priceListApi.getPriceLists()` to get all active price lists
2. **Load Product Prices:** For each price list, calls `productApi.getProductDetail(id?price_list_id=X)` to get product-specific pricing
3. **Display Results:** Shows formatted table with pricing information

### Error Handling
- Graceful handling of missing prices
- Individual price list API errors don't break entire component
- User-friendly error messages
- Loading states for better UX
